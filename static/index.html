Access roles

Admin (existing login) can view everything, change all settings, acknowledge alarms and view the Audit log.

Operator can view readings, trends and alarms, download CSV history under Reports, and acknowledge alarms. Operators cannot see or change Settings and cannot view Audit. Create or change the Operator login on the server with sudo python3 /opt/pbf-wastewater/web/web.py --set-operator USERNAME.
